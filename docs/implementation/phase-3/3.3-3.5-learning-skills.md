# Phase 3 / 3.3-3.5 学习 Skill 模板实现记录

- 状态：实现完成，待 Phase 3 批次验收
- 范围：只新增讲解、测验和卡片三个 Markdown skill 模板，以及框架加载与契约格式测试代码。

## AgentScope 2.0.1 格式与路径核实

本地依赖核实结果如下：

- `WorkspaceConstants.SKILLS_DIR` 固定为 `skills`，即 skill 位于已配置 workspace 根目录的 `skills/` 下。
- `WorkspaceSkillRepository` 在该目录下查找名为 `SKILL.md` 的文件，不加载 `explain.md`、`quiz.md`、`card.md` 这类扁平文件。
- `SkillUtil.createFrom(...)` 要求每个 `SKILL.md` 包含带 `name` 和 `description` 的 YAML front matter，并要求正文非空。
- 当前应用默认 workspace 是 `${user.dir}/.agentscope/workspace`。

因此，本任务把设计中的概念路径 `workspace/skills/explain.md`、`quiz.md`、`card.md` 落为框架实际可加载路径：

- `.agentscope/workspace/skills/explain/SKILL.md`
- `.agentscope/workspace/skills/quiz/SKILL.md`
- `.agentscope/workspace/skills/card/SKILL.md`

## 模板契约

- `explain`：输入知识点、学习目标和来源 chunk；输出讲解、要点、示例和实际使用的 `sourceChunkIds`。
- `quiz`：固定输出 5 道四选一题；每题包含题目、选项、答案、解析和输入中存在的 `sourceChunkId`。
- `card`：固定输出 3-5 张卡片；每张包含 `front`、`back` 和输入中存在的 `sourceChunkId`。
- 三个模板均禁止捏造来源；来源不足时应明确报告不足，不以外部事实补齐。
