# 3.2 KnowledgePointLifecycle 实现记录

## 范围

本任务只实现 `learning` 子域中的纯业务状态流转规则，不接入 Spring、数据库、Controller、模型或事件。

## 选择与依据

- 状态集合固定为 `NEW → EXPLAINING → QUIZ → COMPLETED`，与当前执行方案、技术设计和 V3 `knowledge_points.status` 一致。
- `KnowledgePointStatus` 是业务规则使用的最小 enum，不替换或修改表实体字段。
- `KnowledgePointLifecycle.advance(current, target)` 要求调用方显式提供当前状态与目标状态，便于同时拒绝跳跃、重复和回退；`COMPLETED` 作为终态不能继续推进。
- 非法流转抛出 `IllegalStateException`，缺失状态抛出 `IllegalArgumentException`，失败不会被静默处理。

## 实现结果

- 已编码三个合法的单步流转。
- 已编码跳跃、重复、回退、终态继续推进及空状态的失败测试。
- 按 Phase 3 批次约束，本任务未运行测试或编译，当前状态为“实现完成/待批次验收”。

## 明确不包含

回退、暂停、额外状态、持久化更新、时间字段维护、事务、HTTP 接口、模型调用和事件发布均不在本任务范围内。
