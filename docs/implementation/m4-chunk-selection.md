**冻结配置：结构 child 800 / overlap 0，parent 2400 / overlap 0，正文预算4096，BM25/向量候选各30，RRF k=60。** 依次最大化最差课程Hit@5、宏平均MRR@10，最后比较更低的逻辑embedding token。所选组与800/80有相同Hit@5，MRR略高；逻辑embedding token减少8.66%。这是该开发集合的结果，不是普遍最优参数或真实账单节省证明。

“完整标注证据必须位于单一块”的评分会受分割影响：400/40中3题在任一子块都没有完整引用，固定800/80中1题跨块；结构800/0与800/80均20/20可定位。另以实际上下文及回答评审检查父块回填，不把它算作排名提升。

初始800/80使用的索引混入烟测和留出课程文档，已从正式比较中排除并保留在preflight目录。独立12原件索引复测结果与初始排名指标相同。各组均1个主分片；不同分组按新的物理索引入库，不清除旧证据。六组共120次正式开发检索请求，另20次preflight保留。
