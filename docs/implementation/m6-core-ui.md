# M6 核心学习工作台

本批完成重点计划、完整回合记录、来源抽屉和可恢复流式交互的前端接入。上传仍是原有实现，原生分片和正式上传/压缩实验尚未完成；本文不是 M6 整体完成声明。

## 已实现

- 学习准备选择课件/习题/不使用，只有已索引资料可选；创建持久化规划任务后执行，轮询已保存阶段，失败可查询或继续同一计划。成功后先展示重点、时间估算、习题依据，再建立已有计划的学习会话。
- 学习页使用自然消息与 SSE，不再依赖前端分别调用讲解/出题/制卡接口推进。快捷按钮发送普通自然语言；五题选项转成有序作答文本，仍由后端校验评分。
- 恢复时一起读取会话与完整回合列表，历史测验、评分、三卡按保存产物展示。旧会话没有完整聊天时明示边界，保留原讲解、测验与卡片。
- 请求编号在首次发送时生成，未知结果与重试复用原编号/原消息；以 result.turn 状态判定完成。断开显示不取消后台执行，可查询结果；生成阶段失败可修改消息继续，已提交产物阶段只恢复原回合。输入草稿不会因另一条消息完成而清空。
- SSE 解析缓存跨 UTF-8 字节、CRLF、行及 JSON 的分片；连接结束但没有终态事件视为结果未知。使用 react-markdown 10.1.0 + remark-gfm 4.0.1 显示代码、列表和表格，不执行原始 HTML，不加载模型给出的图片地址。实现依据：[react-markdown 官方文档](https://github.com/remarkjs/react-markdown)。
- 会话响应补充章节 ID/标题、优先级、来源 ID；新增只读 `GET /api/knowledge-bases/{id}/source?chunkId=...`，先检查资料库归属，再校验 chunk 对应文档的用户和资料库，返回真实保存片段。
- 计划、测验和卡片共享来源抽屉。原生 modal dialog 管理焦点，Escape 返回原引用按钮；关闭时恢复滚动。字符区间只显示为字符区间，不伪造页码。
- 统一 DESIGN.md / UX-CONTRACT.md 与运行时语义变量，修复窄屏根布局溢出、隐藏学习页重复读取、创建/改名失败仍清空输入等问题。
