# Phase 0 / 0.4 AgentScope Model provider 配置

- 关联任务：Issue #4
- 状态：实现完成，待批量验收
- 范围：配置 AgentScope 2.0.1 原生 DashScope / DeepSeek provider，并为后续 0.2 的 `HarnessAgent` Bean 提供主 `Model` 依赖。

## 选择与依据

- 主模型固定为 `deepseek:deepseek-chat`。DeepSeek 由 `agentscope-extensions-model-openai` 中的 `DeepSeekModelProvider` 提供，不增加不存在的独立 DeepSeek 扩展依赖。
- DashScope 与 DeepSeek 都通过扩展 JAR 的 `ModelProvider` ServiceLoader 声明交给 `ModelRegistry` 解析，分别使用 `dashscope:<model>` 与 `deepseek:<model>` 前缀；应用不重复注册自定义 factory。
- 生产暴露唯一命名 Bean `agentScopePrimaryModel`。Phase 0 不配置 fallback，也不创建 fallback `Model` Bean，避免把 provider 共存误解为自动降级。
- `maxRetries=1` 作为类型化配置保留给后续 Issue #2 构造 `HarnessAgent` 时使用；本任务不创建或修改 `HarnessAgent` Bean。
- 本任务不提前删除仍有消费者的迁移期 Spring AI 遗留。AgentScope provider 的凭据和 base URL 复用既有 `study-agent.ai` 配置值，未新增密钥字面量，也不记录凭据。

## Runtime 迁移边界

- AgentScope 是唯一目标 Agent Runtime。本任务保留旧 Spring AI Chat/Tool 代码只是为了不在 Harness、工具与学习流程迁完前切断现有调用链，不代表长期保留双 Runtime。
- 禁止新增 Spring AI `ChatModel` / `ChatGenerationService` / `ToolCallbackProvider` 消费者；旧消费者在任务 3.12 统一删除。
- Spring AI Embedding 是 RAG provider adapter，不属于 Agent Runtime；其去留在 RAG 阶段单独决定，任务 3.12 不处理 Embedding。

## 配置

```yaml
study-agent:
  agentscope:
    model:
      primary-model-id: deepseek:deepseek-chat
      max-retries: 1
      dashscope:
        api-key: ${study-agent.ai.embedding.api-key}
        base-url: ${study-agent.ai.embedding.base-url}
      deepseek:
        api-key: ${study-agent.ai.chat.api-key}
        base-url: ${study-agent.ai.chat.base-url}
```

`AgentScopeModelConfiguration` 按模型 ID 前缀选择对应凭据并构造 `ModelCreationContext`，再调用 `ModelRegistry.resolve(...)`。Bean 创建只构造模型客户端，不发起远端请求。

## 测试范围

`AgentScopeModelConfigurationTest` 使用占位凭据和保留的 `.example.test` 地址，覆盖：

1. `ModelRegistry` 能发现并解析 `dashscope:qwen-plus` 与 `deepseek:deepseek-chat`；
2. 命名 Bean `agentScopePrimaryModel` 使用配置选定的 `deepseek:deepseek-chat`；
3. Spring 容器中只存在一个 AgentScope `Model` Bean，fallback 配置为空；
4. `maxRetries` 绑定为已决策的 `1`；
5. 全部断言只构造模型对象，不调用 `stream(...)`，因此不会访问远端 provider。

按当前批次执行纪律，本任务只编写测试，未运行 `mvn compile` 或任何测试；编译、测试与独立验收统一延后到完整批次边界。

## 非本任务范围

- 不创建或修改 `HarnessAgent` Bean，不接入业务调用方；
- 不启用 fallback，不实现运行时自动降级；
- 不修改 AgentScope 或 Spring AI 依赖；
- 不提前删除旧 Spring AI Chat/Tool 调用链，但不得新增消费者；后续清理由任务 3.12 负责；
- 不决定或改动 Spring AI Embedding adapter；
- 不通过远端请求验证模型账号、额度或最终响应。
