# Phase 0 / 0.8 最简 Agent HTTP 链路

- 关联任务：Issue #8
- 状态：实现完成，定向测试与真实 HTTP / DeepSeek smoke 均通过；等待 M0 独立 verifier review。
- 范围：通过一个无请求体的 HTTP 入口验证请求身份到 AgentScope `HarnessAgent` 的最短调用链。

## 已确认契约

- `POST /api/agent/hello`，无 request body 与 query 参数。
- `X-User-Id` 由既有 request-scoped `CurrentUserContext` 解析；Controller 不重复读取或转换请求头。
- Controller 返回 HTTP 200 JSON，响应体为 `ApiResponse<String>`。
- 缺失或非法身份头的稳定 HTTP 错误协议尚未确定，本任务不增加对应映射或断言。

## 实现选择与依据

- `AgentHelloController` 只把当前 `userId` 交给 `AgentHelloService` 并包装统一响应，避免在 HTTP 层放置 AgentScope 调用逻辑。
- `AgentHelloService` 每次调用生成新的 UUID `sessionId`，并构建 `RuntimeContext(userId, sessionId)`。`userId` 转为 AgentScope 2.0.1 API 要求的字符串，服务端身份不会交给模型决定。
- 服务固定调用已由 Issue #2 装配的单个生产 `HarnessAgent` 的 `call("hello", context)`，同步等待结果并通过 `Msg.getTextContent()` 返回模型文本。
- 日志只记录 `userId` 与 `sessionId`，不记录 prompt、模型回复、模型配置或密钥。
- 调用失败保持真实异常，不 catch、不静默降级，也不硬编码模型回复。

## 测试范围

- service 测试使用 mock `HarnessAgent`，验证固定 `hello`、`RuntimeContext` 的字符串 userId、每次调用不同且可解析的 UUID sessionId 及 `Msg` 文本提取；mock 返回本地 `Mono`，不会访问远端模型。
- controller 测试通过 `POST /api/agent/hello` 与 `X-User-Id` 验证既有身份解析、无请求体调用、HTTP 200 JSON 及 `ApiResponse<String>` 字段，并 mock service 防止远端调用。
- `AgentHelloServiceTest` 与 `AgentHelloControllerTest` 已通过。
- 2026-09-04 使用 Docker Compose 依赖和隔离的 `study_agent_m0_smoke` 数据库启动可执行 jar；应用成功应用 V1-V4 migration，并以 AgentScope `deepseek:deepseek-chat` 启动。
- 携带 `X-User-Id: 1` 调用 `POST /api/agent/hello` 返回 `code=0`、`message=ok` 和真实模型文本 `Hello! How can I help you today?`。日志确认模型 reasoning 与响应一致，代码没有硬编码回复。
- Windows runner 禁止 JDK selector 建立 loopback pipe，因此宿主上的 Elasticsearch client 测试与 AgentScope HttpClient 初始化会报 `Unable to establish loopback connection`；相同代码在 Linux JDK21 容器内完成启动和真实请求，未为该环境限制修改生产代码或弱化测试。

## 批量验收步骤

1. 运行 `AgentScopeAgentConfigurationTest`、`AgentHelloServiceTest`、`AgentHelloControllerTest` 及 Phase 0 相关测试。
2. 运行 `mvn compile`，必要时运行全量 `mvn test`。
3. 启动依赖与应用，携带 `X-User-Id: 1` 请求 `POST /api/agent/hello`，确认真实 DeepSeek 返回非硬编码文本并核对日志中的 userId/sessionId。
4. 由未参与本批实现的 verifier 独立审查 M0；通过后在 `PROGRESS.md` 关闭 M0。

## 非本任务范围

- 不配置工具、系统 prompt、memory、trace、compaction、subagent 或 session 持久化策略。
- 不增加 fallback、第二个 agent 或新的 Runtime 抽象。
- 不定义身份失败的稳定错误协议，不改动旧接口中的默认 userId。
- 不实现 M1 的知识库/RAG 工具闭环，不实现 M2 learning/compaction。
