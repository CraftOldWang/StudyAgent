# 0.5 IdentityResolver 实现记录

## Scope

- 新增 `com.studyagent.identity.IdentityResolver`，作为 identity 子域的 Servlet 请求身份解析入口。
- 从 `HttpServletRequest` 的 `X-User-Id` 请求头读取字符串并转换为 `Long`。
- 用单元测试覆盖已确认的成功解析路径。

## 行为

`IdentityResolver.resolve(HttpServletRequest)` 返回 `Long.valueOf(request.getHeader("X-User-Id"))` 的结果。实现不捕获或替换转换异常，因此请求头缺失或内容不是数字时保留 JDK 的自然失败语义。

## 非 Scope

- 不定义缺失或非法请求头对应的 HTTP 状态码、响应体或业务异常。
- 不提供默认用户，不兼容历史代码里的 `DEFAULT_USER_ID`。
- 不实现登录、API token、权限校验或身份上下文传播。
- 不实现 0.6 的 `DataIsolationInterceptor`，也不修改 0.7 的用户表迁移。
