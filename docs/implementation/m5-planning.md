# M5 可恢复学习规划

本模块落实目标契约 5.1：资料覆盖、教学大纲、习题重点和顺序任务。它是学习计划内部的阶段编排，仍使用 AgentScope 模型、Spring Boot 服务和 MySQL，不引入通用工作流引擎。

## API 与持久化

先 `POST /api/learning/plans` 提交 `knowledgeBaseId`、`learningGoal`、`lessonDocumentIds`、`exerciseDocumentIds` 和可选 `targetPointCount`。创建操作只校验并保存资料快照，返回可恢复的 run ID；未指定课件时使用知识库中已索引且未被选为习题的文档。习题与课件不能重复选择。

`POST /api/learning/plans/{id}/execute` 执行或恢复，`GET` 同一路径查询阶段和结果。`POST /api/learning/plans/{id}/session` 将成功任务转换成学习会话，在事务中锁住规划记录；重复或并发请求返回已有会话，知识点沿用大纲阶段分配的稳定 Long ID。

V10 新增 run 和 stage-attempt 表，保留每次尝试的输入指纹、原始输出、解析产物、usage、traceId、状态、错误及耗时。run 的执行令牌与 600 秒租约控制提交权；模型请求在数据库事务外进行，每个阶段开始和结束都检查并续租。过期运行可由同一 execute API 恢复。第一版没有规划后台自动重跑扫描器。

成功阶段输入指纹不变时直接复用。已成功阶段的资料、prompt 或模型配置变化时明确拒绝混用，要求创建新任务；失败阶段可使用修正后的契约重新尝试，每次保存新的输入指纹，上游成功结果继续复用。失败尝试保留，不覆盖为后续成功结果；进程中断导致缺少终态 usage 时仍记为未知，不补零。usage 原始账本以各阶段 traceId 关联实际 provider 尝试。

## 阶段契约

1. `EXTRACT/n`：按选定文档顺序读取所有 PARENT，按正文4800个本地token打包，不跨文档。没有TopK筛掉整份课件。每个来源都需有知识点或未提取说明。v6将父块全文划为最长400字符的连续编号摘录，优先在换行处分隔；模型选择来源和摘录编号，服务端回填原文，避免公式抄写改动。它只是规划阶段的引用锚点，不改变RAG父子切块或embedding。边界、长行覆盖和非法编号有定向回归。
2. `OUTLINE`：合并相近子主题与同义点为章节→知识点，必须消费全部候选，每个候选只归属一次。模型使用C1…Cn短编号，服务端映射回持久Long ID并合并来源及摘录。遗漏检查明确返回未分配编号，用户指定数量时检查列表总数。服务端按chapterTitle分组并分配章节、知识点Long ID，不以模型文本声称覆盖替代集合校验。
3. `EMPHASIS/n`：逐批读取习题，映射到已存在知识点。每个匹配同时包含习题原文与该知识点已经确认的课件摘录；引用的存在性和归属可确定性检查，语义相关性仍需抽查。没有具体对应依据时保留 unmatched，不能仅凭“大体属于同一课程”强行关联。不是独立题库，也不把习题答案当作已验证事实。
4. `EMPHASIS_REVIEW/n`（v5）：存在候选匹配时独立复核习题与课件的短摘录，不传入前一阶段的匹配理由。区分题目要求判断的命题和课件明确支持的命题；每条候选必须有布尔结论和理由。拒绝的匹配保留为带复核原因的unmatched，原始提议、复核输出和失败均持久化。不以词面存在替代语义依据，复核模型仍需真实样本抽查。
5. `TASKS`：所有大纲知识点恰好出现一次，生成先修概念在前的顺序及基础时间。模型只安排教学基础内容，服务端附加已复核的习题理由及时间：HIGH追加10分钟，MEDIUM追加5分钟，NORMAL不追加并明确暂无直接匹配依据。这是一条可解释的练习时间规则，不是考试概率估计或优化器。没有习题时重点为空，基础点照常保留。

单次模型输入上限 28000 本地 token、输出上限 6000 token；超限保留已完成阶段并明确失败，不截断资料或静默少读。重点判断复用短摘录，避免重复送入整门课程全文。参数统一放在 `LearningPlanningProperties`，当前没有逐课程配置。

在编译原理及操作系统真实合并中，非推理模式多次遗漏候选或输出错误数量。当前OUTLINE、EMPHASIS及EMPHASIS_REVIEW启用推理模式，输出总预算16000、effort=low，配置位于`LearningPlanningReasoningProperties`；普通提取和任务编排维持6000。此前high配置在操作系统大纲耗尽15998个输出token且正文为空，失败保留；low配置随后复用13批提取并完成原任务。推理配置只加入相关阶段指纹，未受影响的成功提取结果继续复用。这是显式阶段配置，不是失败后隐藏切换provider。学习/压缩实验继续使用原学习模型选项。

复核曾将一道编号题的多个子问作为一个整体，导致部分有依据的子问也被全部拒绝。当前匹配以单一子问为单位引用；复核获得原习题上下文以解释选项编号，但只判断所引用子问，不要求同一编号下其它子问也有课件覆盖。原提议和拒绝理由继续保留，修正后的语义效果仍须实际抽查。
