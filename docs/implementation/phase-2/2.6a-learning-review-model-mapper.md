# 阶段 2.6a：learning/review 全局 model/mapper

- 对应任务：Phase 2.6 表迁移后的持久化模型机械跟进。
- Scope：只新增与 V3 schema 一一对应的四组全局 model/mapper 和映射测试。
- 状态：实现完成，等待 Phase 2 工具/服务接线批次统一编译、测试和独立验收。

## 实际变更

- 新增 `com.studyagent.model.LearningSession`、`LearningPlan`、`KnowledgePoint`、`ReviewCard`，仅包含 V3 表字段。
- `LearningSession.knowledgeBaseId` 表示单一会话 scope；`ReviewCard` 的 user/knowledge-point/KB 字段属于服务端持久化绑定，不是工具输入字段。
- 主键与其他 `BIGINT` 字段映射为 `Long`，时间映射为 `LocalDateTime`；状态直接映射为 `String`，不提前引入枚举、行为或关联对象。
- `plan_json` 暂按数据库 JSON 文本映射为 `String`，不在持久化实体中引入计划 DTO；可空的 `exported_to_anki` 使用 `Boolean`，与 V3 未声明 `NOT NULL` 的约束保持一致。
- 每个字段显式声明 `@TableId` 或 `@TableField` 列名，避免依赖当前已知失效的全局驼峰配置。
- 新增四个全局 Mapper，只继承对应 `BaseMapper`，不加入自定义 SQL。
- 映射测试通过反射核对表名、字段全集、Java 类型、显式列名及 Mapper 泛型绑定。

## 严格过渡边界

旧 `com.studyagent.modules.review.domain.ReviewCard` 与旧 `com.studyagent.modules.review.infrastructure.ReviewCardMapper` 暂时保留。新旧同名类型仅因包名不同而在编译期共存；本任务不迁移旧消费者、不增加适配层，也不改变现有 Mapper 扫描范围。

新全局 Mapper 当前只参与编译，待后续工具/服务接线批次再注册和切换消费者。因此本任务不是可独立部署的完整功能。
