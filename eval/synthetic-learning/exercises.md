# 纸鹤缓存协议：验收用自编习题

以下全部为新编测试题，不来自真实课程或历年试卷。

1. 在时刻100写入TTL=20，读取不会延长TTL。分别判断119、120和121时的读取结果，说明为什么120已经过期。本题重点检查存活时间的边界。
2. 两个更新请求都携带期望版本3，当前版本为3。为什么最多一个成功？失败请求会不会改变到期时间？本题重点检查版本更新的原子性。
3. 相同requestId与相同输入再次到达，应当直接返回原结果，不增加版本。若第二次输入不同，应返回什么？为什么requestId去重不能替代版本比较？本题重点检查重复请求与并发更新的区别。
4. 一个租户有两项未过期缓存，写入第三项如何选择淘汰对象？成功读取和MISS是否都会更新最近读取时刻？
